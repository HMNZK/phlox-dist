Features

Real orchestration, not copy-paste.

One native cockpit for every coding agent on your Mac — spawn them, watch them, and let them work together.

01 — Parallel

One window, every agent

Codex, Cursor, and Claude Code each run in their own live terminal pane — side by side, in parallel. No tab-juggling, no context lost between apps.

02 — Delegate

Delegate and wait

Spawn a session, send the brief, and let it run. Completion is detected automatically via Stop hooks — then you integrate the result.

03 — Handoff

Agents that talk

Built-in messaging lets sessions hand off work and share context, so a fleet of agents collaborates on one task.

04 — Status

Status you can trust

Running, idle, or waiting for input — detected automatically, including Codex prompt-waits — with notifications and plan-approval prompts so nothing stalls unseen.

05 — Layout

Workspaces & layouts

Group sessions by workspace, filter the grid, switch view modes (⌃⌘G), and toggle the sidebar (⌘B). Your cockpit, your way.
