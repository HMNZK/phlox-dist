概要

Phlox は、複数の AI コーディングエージェントをひとつの画面から操作できる macOS アプリです。 本ポリシーは、アプリが収集する可能性のある情報、その利用目的、およびユーザーの選択肢について説明します。 プライバシーは既定で尊重されます。利用解析は完全オプトインで、既定は無効(OFF)です。 設定画面のトグルを有効にしない限り、個人データは一切収集されません。

収集する情報(オプトイン時のみ・匿名)

利用解析が有効になるのは、以下の条件を両方満たす場合に限られます。

  • 設定画面の解析トグルを有効にしている、かつ
  • アプリに解析用 App ID が設定されている。

上記を満たす場合、プライバシーに配慮した匿名解析サービス TelemetryDeck を通じて、以下の最小限の匿名イベントのみを送信します。

  • アプリ起動 — パラメータなしで記録されます。
  • セッション作成 — エージェント種別の識別子のみを記録します（例: claudeCode、codex、cursor）。その他のセッション情報は含まれません。

収集しない情報

以下の情報は一切収集・送信しません。

  • 氏名・メールアドレスなど個人を特定できる情報
  • ファイルパス・セッション名・ワークスペース名
  • AI エージェントへ送信したプロンプトや受信した回答
  • コードやファイルの内容
  • 個人を特定できる識別子

利用目的

上記の匿名イベントは、どの機能が使われているかを把握し、アプリの改善優先度を判断するためにのみ使用します。 広告・プロファイリング・製品開発以外の目的には使用しません。

第三者サービス

  • TelemetryDeck — プライバシー配慮型・匿名の解析サービス（EU ホスティング・GDPR 対応）。 上記の条件で解析が有効な場合にのみ使用します。 詳細は TelemetryDeck のプライバシーポリシーをご覧ください。
  • GitHub — アプリの配布リリースをホストしています。 ダウンロード数は GitHub が提供する集計値であり、個別ユーザーを特定するものではありません。
  • Sparkle — アップデート配信に使用するオープンソースの macOS フレームワーク。 アップデート確認のためにネットワークリクエストを行う場合がありますが、個人情報は送信されません。

オプトアウト(無効化方法)

利用解析は既定で無効(OFF)です。 トグルを有効にした後に無効に戻したい場合は、アプリの設定画面を開き、解析トグルをオフにしてください。 それ以降、データは送信されません。

ダウンロード統計

ダウンロード数は GitHub の公開リリースが提供するダウンロードカウンタ（集計値）で把握しています。 これは合計数であり、個別のユーザーやデバイスを特定するものではありません。

ポリシーの変更

本ポリシーに重大な変更がある場合は、新しい施行日とともにこの URL に掲載します。 施行日以降にアプリを継続して使用した場合、改訂後のポリシーに同意したものとみなします。
