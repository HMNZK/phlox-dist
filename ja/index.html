AIコーディングエージェントを、
束ねて動かす。

Phlox は Codex・Cursor・Claude Code を1つのネイティブ macOS コックピットで並列に動かします。セッションを spawn し、タスクを委譲し、結果を統合する — すべて1画面で。

macOS版をダウンロード
macOS 14 Sonoma 以降 · Apple Silicon · 署名・公証済み

コピペではない、本物のオーケストレーション。

🪟

1画面に、複数のエージェント

各エージェントが専用のターミナルペインで動作。Codex・Cursor・Claude Code が並列で働く様子を、タブを行き来せずそのまま見られます。

⚡

委譲して、待つ

セッションを spawn し、指示を送り、完了を待つ — 完了は Stop フックで自動検知 — そして結果を統合します。

💬

エージェント同士が会話する

セッション間メッセージングで作業を引き継ぎ、文脈を共有。複数エージェントが1つのタスクで協調します。
