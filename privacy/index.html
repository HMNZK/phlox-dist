Overview

Phlox is a macOS application that lets you orchestrate multiple AI coding agents from a single window. This policy explains what information the app may collect, how it is used, and the choices you have. Privacy is respected by default: analytics are completely opt-in and disabled by default. No personal data is collected unless you explicitly turn on the analytics toggle in Settings.

Information collected (opt-in only, anonymous)

Analytics are active only when both of the following conditions are met:

  • You have enabled the analytics toggle in the app's Settings screen, and
  • An analytics App ID has been configured in the app.

When active, only the following minimal, anonymous events are sent via TelemetryDeck, a privacy-focused analytics service:

  • App launch — recorded with no additional parameters.
  • Session created — records only the agent-kind identifier (e.g., claudeCode, codex, cursor). No other session data is included.

Information not collected

The following data is never collected or transmitted:

  • Name, email address, or any other personally identifiable information
  • File paths, session names, or workspace names
  • Prompts sent to AI agents or responses received from them
  • Code or file contents
  • Any identifier that could be used to identify an individual

Purpose of use

The anonymous events described above are used solely to understand which features are being used and to prioritize improvements to the app. They are not used for advertising, profiling, or any purpose other than product development.

Third-party services

  • TelemetryDeck — privacy-preserving, anonymized analytics (EU-hosted, GDPR-aware). Used only when analytics are enabled as described above. See TelemetryDeck's privacy policy.
  • GitHub — hosts the app's distribution releases. Download counts are aggregate figures provided by GitHub and do not identify individual users.
  • Sparkle — the open-source macOS update framework used to deliver app updates. Sparkle may make network requests to check for updates; no personal data is sent.

Opting out

Analytics are disabled by default. If you have enabled the toggle and wish to stop sending analytics, open the app's Settings screen and turn off the analytics toggle. No data will be sent from that point forward.

Download statistics

Download counts are tracked via GitHub's public release download counters. These are aggregate totals and do not identify individual users or devices.

Changes to this policy
